# Triage labels

Use the GitHub label that corresponds to the role named by the skill.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | The issue needs more information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is specified enough for an agent to implement independently. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation. |
| `wontfix` | `wontfix` | The maintainer has decided against pursuing the issue. |
